# チェインブラスター 全消しボイス

- `beautiful-whoa.mp3`: 「ビューティーホォー！」(全消しボーナス演出用ボイス)
- 生成方法: PixVerse CLI `pixverse create voice`(MiniMax `speech-2.8-hd`、プリセット音声 `minimax_japanese_optimisticyouth` / Optimistic Youth、`--emotion happy`)によるAI音声合成
