GAME START

パドルはドラッグ / 矢印キー / コントローラーのスティック・十字キーで移動。タップ / Space / コントローラーAボタンでボール発射。反転ボタン(Space / コントローラーBボタン)で上下の攻め先を切り替える。

くわしいルール(モンスター・ボス・ボール増加など)はプレイ中に⏸ボタン(P / Escape / コントローラーStart)でいつでも確認できる。

PAUSE

ブロックは上下両方に配置されている。反転ボタンで重力方向を反転すると、ボールとパドルの上下関係が入れ替わり、攻める面を切り替えられる。反転には短いクールタイム(例:0.6秒)があり、連打はできない。
耐久1 のブロック。1発で破壊。
耐久2 のブロック。2発で破壊。
壊したブロックはそのまま消える(再生しない)。並び方はステージごとに変化する。上下のブロックを全て壊すとステージクリア。
画面中央のモンスターはブロックを壊すたびにダメージを受ける(耐久が高いブロックほど大ダメージ)。倒すと見た目の違う次のモンスターが際限なく出現し続ける(倒すたびにスコアボーナス)。ステージクリアには影響しない、腕試し用の相手。ステージ2のみ2体同時出現(HPは共有)。
モンスターの技:一定間隔でランダムな角度の弾を放ってくる。反転ではなくパドルの左右移動で避ける。倒した数が増えるほど間隔が短くなり難しくなる。
ボール発射から5秒後に2個目が自動で発射され、以降は10秒ごとにボールが1個ずつ増え続ける(際限なし)。
倍速ボタン(1x⇔2x)でボール・パドル・妨害弾の速さを切り替えられる。
🔊ボタンでBGM・効果音のオン/オフを切り替えられる(設定は次回プレイ時も記憶される)。
3ステージ勝ち抜くごとに(4・8・12ステージ目)ボスステージが出現する。
ボス面の装甲。囲まれたコア(装甲を全て崩すと露出)を攻撃してHPを削り切れば撃破。コアHPは上下面で共有。
妨害弾(ボス面のみ)。反転ではなくパドルの左右移動で避ける。
